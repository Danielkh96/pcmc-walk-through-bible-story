# 第三章｜日月星辰

状态：用户已确认分镜稿 v1，并于 2026-09-10 授权生成全部图片及发布到现有 GitHub → Vercel 网站。下列批准内容保持不变；绘图提示词与检查记录另行保存。

## 范围与节奏

- 经文：创世记 1:14–19；第四日。
- 正文：10 页、46 格。逐页格数：5 / 5 / 3 / 5 / 4 / 5 / 5 / 5 / 4 / 5。
- 接续第二章最后一格：小昆问太阳什么时候出现，小君也想看；两人仍在已有天、海、陆地和植物的观察空间中。
- 本章主线：寻找太阳 → 神设立光体的命令 → 两个大光 → 日光下的世界 → 月夜 → 众星 → 光体的功用 → 与生活中记日子的联系 → 第四日结束 → 对飞鸟的好奇。
- 情绪：期待、惊喜、安静欣赏、朋友间开玩笑、继续探索。
- 10 页而非固定 12 页：为日、月、星辰各留足画面，不用额外对白拖长同一事件。

## 固定设定

- 小昆：已批准的圆润 Q 版，蓬松短发、橙色上衣、深蓝裤、深蓝背包、白橙鞋。小君：半扎发与湖绿发圈、湖绿上衣、米色裤、一个棕色斜挎包、白绿鞋。
- 两人均为现代虚构观察者，不安排恋爱，不让小君变成全知讲解员，不把小昆画成只会犯傻的人。
- 不新增人物，不重复人物介绍页。神不具象化，不出现耶稣、天使或为神编写的对白。
- 继续站在微弱透明观察光纹内，没有回阅读角、没有带着圣经、没有新增手机、望远镜、日历道具或时光机器。
- 第四日之前已有光与昼夜，不能写成太阳出现才第一次有光或昼夜。
- 依据和合本的经文旁白与虚构角色对白必须分开：矩形框是经文，气泡是两人聊天。经文只调整标点和分格，不改词。和合本是中文译本，不宣称希伯来文逐字原文。
- “大的管昼／小的管夜”用太阳与月亮的画面表达，不借机解释天体实际尺寸比较；不把月亮画成火球或独立燃烧发光的星体。
- 第 3–8 页的白天与夜景是第四日创造及功能的分镜展示，不是多个额外日子的时间纪录。只在第 9 页正式用经文标明第四日结束。
- “节令、日子、年岁”的功能可以联系生活，但不描绘现场已经过去一年、四季循环或现代历法已被制定。
- 没有鱼、鸟、陆地动物、昆虫、亚当或夏娃；不为画面可爱加入蝴蝶、海鸥或萤火虫。可以在虚构对白中提及现代生活中见过的鸟，但画面中不能提前出现。
- 所有镜头、动作、排版和备注仅供制作；学生只看批准的经文旁白、对白和片尾预告。下列页标题也不自动印进图内。

## 第 1 页｜还在找太阳（5 格）

排版：上方横格，中间两格，下方两格。接续第二章，天空仍只有原有的明亮，尚不画日月星辰。

1. **远景。** 两人背影在画面下方，前景草叶、远景海湾与天空，延续第二章地形关系。**无台词。**
2. **小昆侧面近景。** 手放在眉前，左右寻找，带一点认真过头的可爱。**小昆：还是没看到。**
3. **小君近景。** 看看天空，再笑着看看小昆。**小君：你都快把天空看遍了。**
4. **双人中景。** 小昆放下手，握住背包肩带，认真但带着笑。**小昆：这个问题，我今天一定要弄明白。**
5. **双人背影窄格。** 两人安静下来，视线都移向远方，准备承接经文；没有特殊声响、神的脸或替他们说话的光球。**无台词。**

## 第 2 页｜天上要有光体（5 格）

排版：前三条横格连续承载同一句命令，下方两格角色反应。对白不遮住经文。

1. **天空远景。** 辽阔天空和陆地同框，还不提前给光体特写。**经文旁白：神说：“天上要有光体，可以分昼夜，**
2. **地景横格。** 镜头向海湾、树木移动；不加现代钟表和日历。**经文旁白：作记号，定节令、日子、年岁，**
3. **广角环境。** 保持创造命令的整体感，不画天体爆炸。**经文旁白：并要发光在天空，普照在地上。”事就这样成了。**（以上创 1:14–15）
4. **小昆近景。** 他本来只想找太阳，此刻留意到命令还提了其他事情。**小昆：日子、年岁……连这些都有关系？**
5. **小君中近景。** 坦然表示自己也在学习，再望向天空。**小君：我也没想到。继续看。**

## 第 3 页｜两个大光（3 格）

排版：上方一条窄横格，下方两个大格并列，分别呈现昼景与夜景。这是对应经文的画面对照，不是把太阳月亮拼成同一时间的天空。

1. **两人越肩远景。** 主角缩在底部，天地占主导。**经文旁白：于是神造了两个大光，**
2. **白天大格。** 天空有清楚但不过曝的太阳，日光照着海与植物；主角不直视太阳。**经文旁白：大的管昼，**
3. **夜景大格。** 对应地景在月夜中展现；月亮为自然圆形月面，没有人脸，暂不安排众星特写。**经文旁白：小的管夜，**（以上创 1:16）

注意：两个天体的角直径与画面大小是构图选择，不拿太阳与月亮在画里的大小讲述经文没有给出的天文学细节。

## 第 4 页｜终于看到了！（5 格）

排版：上方横格，中间两格，下方两格。通过植物和海面展示日光，不让角色反复仰头直视太阳。

1. **白天地景。** 日光下的叶片、海湾、清晰树影；太阳可在远景画角，不能像近处巨大火球。**无台词。**
2. **小昆近景。** 注意到太阳后立即把视线移向周围地景，开心地回头叫小君。**小昆：找到了，真的是太阳！**
3. **小君中景。** 看向小昆，笑着接上他前两章一直问的问题。**小君：你刚才的问题，有答案了。**
4. **双人侧面。** 小昆放松肩膀，两人看向明亮的树冠。**小昆：等了这么久，终于看到了。**
5. **越肩看海。** 两人很小，波纹上的光点占主导；不是发光鱼或金色实体漂浮物。**小君：哇，看那片海，亮闪闪的。**

## 第 5 页｜月亮与倒影（4 格）

排版：上方大横格，中间两格，下方横格。仍属第四日受造光体的展示，不加新的日数字幕。

1. **月夜大景。** 与前页可辨认的海湾、树木在月夜中展现，自然月面和柔和倒影；没有昆虫、猫头鹰或其他动物。**无台词。**
2. **小昆近景。** 看向月亮，眼神兴奋但放低声音。**小昆：月亮也看到了！**
3. **小君越肩指向海面。** 清楚看见水面拉长的月光倒影，不画第二个月亮漂在水里。**小君：看，水上还有它的倒影。**
4. **双人背影横格。** 两人安静看海，暖色衣服在月光中稍微降低饱和度，造型不变。**小君：跟白天的感觉完全不一样。**

## 第 6 页｜这么多星星！（5 格）

排版：上方一大横格约占四成，下方四格。星空保持自然细小星点，精致而不变成霓虹宇宙。

1. **星空大格。** 众星在广阔夜空中铺开，月亮可在边缘保持同一世界的连续性；不画星座连线、银河旋涡或流星雨。**经文旁白：又造众星，**（创 1:16）
2. **小昆近景。** 手指轻轻朝不同星点移动，试着数。**小昆：一、二、三……**
3. **小君反应。** 转头看他，忍着笑，并非嘲笑。**小君：你真的要一颗一颗数啊？**
4. **小昆反应。** 视线来回寻找，自己也笑了。**小昆：等等，我刚才数到哪一颗了？**
5. **双人背影。** 小昆放下数星星的手，小君与他并肩看天空，留一格静静欣赏。**无台词。**

## 第 7 页｜不只是好看（5 格）

排版：前三格用天、地、昼夜分别承载经文，下面两格自然接话；不画反复升起落下的多个太阳。

1. **天空与地面广景。** 从受造光体回到完整天地的关系，画面采用白天视角。**经文旁白：就把这些光摆列在天空，**
2. **日光下的地景。** 叶片、树影、海面细节，区别上一格全景。**经文旁白：普照在地上，**
3. **对应的夜景。** 月亮和星星之下的同一海湾，保持构图可识别。**经文旁白：管理昼夜，分别明暗。**（以上创 1:17–18）
4. **小昆中景。** 回想刚刚看到的景色，说出简单发现，不讲长篇结论。**小昆：所以，不只是让天空变漂亮。**
5. **小君近景。** 点头，接回本章开头经文的用词。**小君：对，还有刚才说的日子和年岁。**

## 第 8 页｜日子跟我们也有关（5 格）

排版：上方横格，中间两格，下方两格。夜景环境延续第 7 页末格；这页是虚构角色联系生活，不是额外经文解释或回到现代的插叙。

1. **双人中景。** 小昆一边想，一边用手比划，依然站在观察空间。**小昆：我平时只会看今天几号，还真没想过这些。**
2. **小君近景。** 提起两人熟悉的生活，没有取出书包里的道具。**小君：还有什么时候上学、什么时候放假。**
3. **小昆近景。** 一听到放假就笑起来。**小昆：说到放假，我就很会记。**
4. **小君侧面。** 自然接梗，不摆老师训人的姿态。**小君：那功课几时交呢？**
5. **双人近景。** 小昆稍微停顿，然后笑着承认；小君笑着听。**小昆：那个……也得记。**

## 第 9 页｜这是第四日（4 格）

排版：上方完整景观，中间两格晚上与早晨，下方人物横格。本页才正式收束第四日。

1. **完整地景。** 以日光中的天空、海湾与植物呈现和谐景观。**经文旁白：神看着是好的。**（创 1:18）
2. **晚上。** 相同机位变成月夜，天上已有月亮与星星。**经文旁白：有晚上，**
3. **早晨。** 对应构图呈现日出与晨光；此时可以画太阳，不能误沿用前三日的禁画要求。**经文旁白：有早晨，是第四日。**（以上创 1:19）
4. **双人中景。** 小昆伸出四根手指，笑着看向小君；小君也笑。**小昆：第四天。我这次有记住！**

## 第 10 页｜怎么这么安静？（5 格）

排版：上面两格、中间两格、下方一大格。以“听”而非再次找光源收尾，给第五日的生命留悬念。

1. **清晨环境中的双人中景。** 两人看看天空、海面和树冠。**小君：现在有天、有海，还有这么多树。**
2. **小昆近景。** 他安静下来，微微侧头听，手放松不搞夸张动作。**小昆：可是……好安静啊。**
3. **小君反应。** 看着他的动作，有点好奇。**小君：你在听什么？**
4. **小昆与空树枝同框。** 看向枝头，提起现代生活经验；树上实际没有鸟。**小昆：鸟叫。平时树上不是常常有鸟吗？**
5. **大背影格。** 两人望着空枝与天空，远处海面也没有鱼跃出；有海浪，不营造世界完全无声音的事实断言。**小君：对哦，这里还没看到。**

页脚片尾：**下一章｜海里的生命，天空的飞鸟**
