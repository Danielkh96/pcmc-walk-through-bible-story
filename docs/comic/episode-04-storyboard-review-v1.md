# 第四章｜海里的生命，天空的飞鸟

状态：用户于 2026-09-10 确认本稿，并授权生成全部图片、加入 App 及同步到 GitHub 和 Vercel。以下批准分镜保持不变，绘图与检查记录另行保存。

## 范围与节奏

- 经文：创世记 1:20–23，和合本；第五日。
- 10 页、46 格；逐页格数：4 / 4 / 5 / 5 / 5 / 5 / 4 / 5 / 4 / 5。
- 接续第三章结尾：小昆和小君面对空树枝，寻找鸟叫声。他们继续作为虚构观察者观看创造，不改变圣经事件。
- 主线：安静等待 → 神的命令 → 大鱼 → 各样水中生命 → 飞鸟出现 → 观察飞行 → 神看着是好的 → 赐福 → 第五日结束 → 好奇地上的动物。
- 画面主角转向水中生命和飞鸟，以水下全景、清水俯视、羽翼特写、树梢与飞行轨迹区分页面。避免每页重复同一海湾与双人背影。
- 不新增具名角色，不额外插入人物介绍；新出现的鱼和鸟是场景生命，不拟人化成会讲话的向导。

## 固定设定与经文边界

- 小昆：圆润 Q 版、蓬松深棕短发、橙色上衣、深蓝长裤、深蓝背包、白橙鞋。
- 小君：圆润 Q 版、半扎棕发、湖绿发圈与上衣、米色长裤、一个棕色斜挎包、白绿鞋。两人是朋友，不加恋爱线。
- 承接已批准的精细彩色漫画；黑色分格线、白色沟槽、自然有层次的光影，不变成真人、极简或低细节卡通。
- 二人在原有微弱透明观察光纹中；不是实体平台、玻璃底船或时光机器。水下格是叙事镜头，不是两人潜水；人物反应格保持岸边观察的空间关系，不发明水下呼吸能力。
- 神不具象化，不画手、脸、人形、神性光球或天使；不安排耶稣出场或新增神的台词。
- 经文在矩形框，虚构对白在有明确归属的气泡。旁白采用和合本措辞，只分格与调整标点，不把中文译本称为希伯来文逐字原文。
- 鱼、鸟的外形与动作是艺术表达；经文没有列明具体物种，故不用漫画指定某种现代物种就是经文的唯一所指。“大鱼”不擅改成鲸鱼、恐龙或神话海兽。
- 第 1 页仍无鱼鸟；第 2 页宣告命令；第 3 页开始呈现水中生命，第 5 页呈现飞鸟。分镜逐项展开不代表经文提供了精确到分钟的出现顺序。
- 太阳、月亮、星星和植物已经存在，可以正常使用；不重复光体创造，不提前出现走兽、蛇、昆虫或亚当夏娃。地上允许飞鸟栖息，不能错误地把全部地面生命都禁止。
- 不画鱼鸟互相捕食、死亡、受伤或惊吓追逐；不画鸟啄昆虫，避免提前带入其他生命或本段未叙述的情节。人物不抓鱼、喂鸟或干预受造物。
- 不画建筑、海岸灯火、渔船、网、钓竿、路灯、水族馆、现代学习道具。微弱观察光纹只在人物附近，不蔓延成岸边城镇灯。
- 神的赐福不画成几分钟内孵化繁殖、多代变迁；以丰富的鱼群和飞鸟承载经文，不替经文发明繁殖过程。
- 天空和水面的全景可用同一画格作上下空间对照，但不能把光纹包成水下球体。每格只承担一项清楚的动作。
- 以下页标题、镜头说明、说话人标签和经节备注只作生产资料，不印在漫画内。仅批准旁白、气泡、最后的片尾预告出现在成图中；不额外加拟声词。

## 第 1 页｜再听一下（4 格）

排版：上方横格，中间两格，下方横格；从树枝转向水面，不再重演整页仰望天空。

1. **空树枝特写。** 接续上章的叶片和枝头，背景是已有日光的海湾。叶片轻动但没有鸟、鱼或昆虫。**无台词。**
2. **小昆近景。** 侧耳、手掌轻靠耳边，认真分辨声音，不画巨大耳朵或夸张音效。**小昆：风声、海浪声……就是没听到鸟叫。**
3. **小君中近景。** 看向小昆，再自然转向海湾，微笑但不是早已知道答案。**小君：那就看看，接下来会有什么。**
4. **俯看清水。** 波纹掠过水下岩石，只有自然水波，还没有鱼影；为下页命令留停顿。**无台词。**

## 第 2 页｜水里和天上（4 格）

排版：上方两条横格承载经文，下方双人各一格。前两格不能先画完鱼群和飞鸟。

1. **海面远景。** 宽阔海面，清晨光线，人物只在边角或不出现。**经文旁白：神说：“水要多多滋生有生命的物；**
2. **树冠与天空。** 镜头抬高，留出开阔天空；不画神的实体或文字从人物口中发出。**经文旁白：要有雀鸟飞在地面以上，天空之中。”**（创 1:20）
3. **小昆反应近景。** 先看海面再抬眼，兴奋而不是疑神的话。**小昆：水里和天上都有？**
4. **小君反应近景。** 开心地看看两边，手势自然。**小君：两边都要看了！**

## 第 3 页｜那条好大！（5 格）

排版：上方大横格约四成，中间两格，下方两格。用大鱼体量和较小鱼群对比，不把大鱼画成怪物。

1. **水下广角。** 体型硕大的鱼形水生动物从蓝色水域中游过，自然躯体，不画恐怖牙齿或人的表情。只有镜头入水，主角不在水里。**经文旁白：神就造出大鱼**（创 1:21，句子下页继续）
2. **水面俯视。** 清水下可辨的大体形缓缓转向，以水纹和局部身体表现尺度，不像黑色威胁阴影。**无台词。**
3. **小昆岸边近景。** 从观察光纹内低头看，眼睛睁大，手仍握背包肩带。**小昆：那条也太大了吧！**
4. **小君中景。** 指向大鱼旁边的水域，不探身出光纹或伸手摸鱼。**小君：旁边还有一群小鱼！**
5. **水下侧面横向构图。** 大鱼和较小鱼群在不同深度经过，明确非捕食关系；不能暗示小鱼全是它的孩子。**无台词。**

## 第 4 页｜水里忙起来了（5 格）

排版：上方一大格，中间两格，下方两格；鱼群的方向、体形和层次成为视觉重点。

1. **水下丰富全景。** 长短、体形、鳍尾不同的鱼群各有层次，水色由近处青绿向远处深蓝渐变，不贴物种标签。**经文旁白：和水中所滋生各样有生命的动物，各从其类；**（接创 1:21）
2. **小昆俯看水面近景。** 目光跟着两个不同方向的鱼群移动，不画人物在海底。**小昆：这群往左，另一群又往右……**
3. **小君反应。** 看看忙不过来的小昆，自然接话。**小君：你先看一群就好啦。**
4. **小昆中景。** 又注意到另一片鱼群，笑着指给小君看，不嘲笑他笨。**小昆：不行，那边也好好看！**
5. **鱼群细节。** 近景的鳍、尾和反光，远处另一群转弯；不画昆虫、陆地动物或捕食情节。**无台词。**

## 第 5 页｜真的听到了！（5 格）

排版：上方大横格，中间两格，下方两格；第一次完整呈现飞鸟，呼应第三章的悬念。

1. **仰视大景。** 各样飞鸟在树冠之上展开翅膀，有远近与形态区别，不能让整个天际密到看不见天空。**经文旁白：又造出各样飞鸟，各从其类。**（创 1:21）
2. **枝头特写。** 对应第一页原本空着的树枝，一只小鸟张开喙鸣叫，爪子自然抓枝，不添加文字音效。**无台词。**
3. **小昆近景。** 听到声音、抬起头，开心转向小君。**小昆：听到了！真的有鸟叫！**
4. **小君越肩中景。** 指向枝头给他看，手指不触鸟。**小君：这次不用再找了，就在那边。**
5. **树梢与飞行中景。** 另一只鸟从枝头展开双翼，原来的鸟仍在枝上；两人在下方边角静静看。**无台词。**

## 第 6 页｜翅膀张开的时候（5 格）

排版：上方横格，中间两格，下方两格。以滑翔和振翅两种可观察动作形成差异，不添加飞行教程或额外科学结论。

1. **翼面与侧面飞行特写。** 一只较大飞鸟展开双翼平稳滑过，羽毛层次清楚；视角贴近飞鸟，不是人物长出翅膀。**无台词。**
2. **小昆半身。** 抬眼追随，肩膀放松，不跳跃、不站悬崖边。**小昆：哇，它都不用一直拍翅膀。**
3. **小君中近景。** 发现另一只较小的鸟，望向与前一格不同的位置。**小君：另一只拍得好快，你看！**
4. **小鸟振翅特写。** 清楚的双翼和羽毛，少量动作线，不画成四只翅膀。背景虚化的树叶里没有虫。**无台词。**
5. **双人侧面与前景飞鸟。** 鸟自然经过附近，两人注视，但它不穿过光纹、不停在他们身上。**小昆：这只飞得好近！**

## 第 7 页｜不一样的世界（4 格）

排版：上方大格，中间两格，下方窄横格；连接水里和天上，不变成长篇总结。

1. **单格上下水面视角。** 上部是掠过海湾的鸟，下部是清水中的鱼，明确只是一格跨水面的艺术镜头。**经文旁白：神看着是好的。**（创 1:21）
2. **小昆中景。** 回看整个环境，表情从兴奋转为认真欣赏。**小昆：刚才还只有海和树，现在到处都在动。**
3. **小君近景。** 望向最初那根树枝，轻声接话。**小君：连那根空树枝上，都站着鸟了。**
4. **树枝特写。** 复用第一页第一格的机位，如今有鸟自然栖息，背景有海面波纹；让前后差异自己说话。**无台词。**

## 第 8 页｜神赐福给它们（5 格）

排版：前三条横格承载完整赐福经文，下方两格人物；画面表现已有生命的丰富，不快进繁殖过程。

1. **海与天空全景。** 水中鱼群和空中飞鸟同处自然世界，没有神的手或光束点名个体。**经文旁白：神就赐福给这一切，说：**
2. **水下鱼群。** 由近到远体现丰富层次，保留水体空间，不挤满画格。**经文旁白：“滋生繁多，充满海中的水；**
3. **飞鸟与枝头。** 有飞行与栖息的鸟，不画蛋瞬间孵化或一格多代生长。**经文旁白：雀鸟也要多生在地上。”**（创 1:22）
4. **小昆近景。** 目光仍在鱼鸟身上，说出刚刚留意的经文内容。**小昆：原来，神也赐福给它们。**
5. **小君中近景。** 点点头，像朋友分享自己的阅读经验，不充当讲道角色。**小君：这一段，我以前读得太快了。**

## 第 9 页｜这是第五日（4 格）

排版：上方两格晚上与早晨，下方两格人物；用五根手指呼应天数，但不是再复制上章的整页机位。

1. **夜景。** 月亮与星星在海湾上，鸟栖在枝头，水面有波纹，没有夜市灯光或萤火虫。**经文旁白：有晚上，**
2. **早晨。** 晨光下鸟从树梢飞起，清水中的鱼群清楚可见。**经文旁白：有早晨，是第五日。**（创 1:23）
3. **小昆中近景。** 张开一只手的五根手指，另一手握肩带，不出现六指。**小昆：第五天，有鱼，也有鸟了。**
4. **小君近景。** 笑着看向飞鸟，记忆与刚才的体验相连。**小君：这次我一定记得。**

## 第 10 页｜那地上呢？（5 格）

排版：上方两格、中间两格、下方大格；视线从天空和水面降到草地，作为下一章悬念。

1. **小昆中景。** 一边看远处鱼鸟，一边将目光移向岸上的草地。**小昆：天上、水里都这么热闹了。**
2. **小君反应。** 留意到他的目光转向地面，好奇地问。**小君：你在看哪里？**
3. **小昆侧面近景。** 看着草地，不指向已经出现的走兽。**小昆：地上啊。会不会也有新的？**
4. **低机位草地特写。** 草叶、石头、树根和日光，没有脚印、尾巴、爪子、昆虫或躲藏动物，避免提前揭示。**无台词。**
5. **双人侧后方大景。** 两人在光纹中望向开阔草地，鸟可以在远处树冠之上，但草地不出现第六日的动物。**小君：我们接着看。**
