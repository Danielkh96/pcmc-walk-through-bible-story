# 第一集对白口语化校对 v2

## 校对结论

有以下不自然之处：省略过多让对话像标签（“先待在一起”）；讲解多于现场反应（“先有光，原来是这样”）；作者替角色总结（“可以让我停下来，看这么久”）；有些笑点缺少完整接话。新版改成朋友间互相回应、短句与适量语气词，不改变经文事件。

## 需在绘图同步时处理

- 第1页“毕业”笑点改得更口语，第12页用“还嫌它厚吗”自然呼应。
- 第3页末句“我还碰了一下”对应伸手试触光点，不表示成功抓到实体。
- 第4页“桌子怎么也不见了”对应逐渐淡去的场景，不新增剧情。
- 第5页先问“你没事吧”，再回答；气泡必须按读序排。
- 第9页最后一句仍由小昆说；保持疑问，不让他凭空讲解光的来源。
- 第12页同时修正既有重复人物和误回阅读角的画面；不得仅换文字就标完成。

## 朗读检查标准

逐格连读，而不是只看单句。每句应回应上一句或眼前新变化；连续的“解释道理”应改成观察或疑问。适度使用本地年轻人熟悉的“耶、欸、哦”，不强行每句加词，不幼儿化两人的思考能力。
