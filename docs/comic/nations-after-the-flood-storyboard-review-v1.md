## 故事目标与因果链

小昆上一章问后代住到哪里 → 旁白说明本章先把洪水以后许多代的家族展开 → 先看雅弗后裔分居的概述 → 转到含这一支，并沿古实找到宁录 → 经文在名字间停下来记猎户与城邑，镜头随之从人转到城 → 含的另一支是已经提过的迦南，后代也成为许多家族 → 再转到闪，沿亚法撒、沙拉、希伯找到两个分支 → 法勒与约坍提醒读者家族不断分开 → 三支合起来回答“住到哪里”：不同地土与邦国 → 两人注意到经文也提到不同语言，由这个具体问题引向下一章巴别塔。

这是读经顺序，不是编造人物互相推动的冒险。**第10章概述不能画成挪亚死后才出生的所有后裔，也不能画成第10章结束后人们才突然从多种语言变回一种。** 第1页明确回看许多代，第8页以叙述视角转接下一段；巴别塔的事件留在下一章完整解释。

主角状态：已认识挪亚、闪、含、雅弗和迦南的名字；刚听到挪亚的寿数记录。他们不知道宁录、后代家谱或语言变乱的原因。没有实体圣经、纸、地图、手机或新增道具；不接触古代人物、不引导迁徙。家谱框是给读者看的叙述图层，不是他们手里的地图、会发光的卷轴或能踩上去的道路。
