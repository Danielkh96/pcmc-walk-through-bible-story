# 第二章｜天空、海洋与陆地

状态：分镜 v1 已获用户确认，用户已授权生成整章并发布到现有 GitHub/Vercel。正文保留批准稿内容；实际图片与发布检查另记于 episode-02-publication.md。

## 本章安排

- 经文范围：创世记 1:6–13；第二、第三日。
- 正文：12 页，58 格。每页格数：5、5、3、5、5、4、5、6、6、5、4、5。
- 承接第一章第 12 页：两人仍在透明观察空间内，没有返回阅读角，圣经没有随身携带。
- 剧情线：发现上方变化 → 看见水分上下与天空 → 第二日结束 → 水聚集、旱地显露 → 地与海 → 青草、结种子的植物、结果子的树 → 第三日结束 → 留下第四日的期待。
- 情绪线：期待 → 惊讶 → 认真观察 → 轻松接话 → 对下一步好奇。
- 本章不加入危机追逐、掉进水中或触碰创造的剧情；两人不是创造事件的参与者。

## 人物及文字规则

- 小昆：圆润 Q 版约三头身；蓬松短发、橙色上衣、深蓝长裤、深蓝背包、白橙鞋。主动提问，也能发现细节。
- 小君：相同画风；半扎发、湖绿发圈、湖绿上衣、米色长裤、棕色斜挎包、白绿鞋。细心但不是全知讲解员，也会疑惑、开玩笑。
- 单人正面/侧面、双人背影、环境、细节交替，不反复使用相同站位。双人正面默认小昆左、小君右；反打镜头须保持空间关系和各自道具一致。
- 本章没有新人物，不新增重复的人物介绍页；以后经批准上线时，章节介绍引用现有两位角色资料。
- 神的创造用矩形经文旁白呈现；不画神的人形、手、脸，也不加入耶稣或替神创作台词。
- 下文“画面”“排版”“注意”是制作指令，不印进学生漫画。只印标明的旁白、对白与片尾字。
- 经文引自中文和合本，保留词语，仅采用现代标点并按分镜断开；不是希伯来文原文。两位主角的对话和穿越空间属于虚构框架。
- 旁白框与角色气泡形状分开。每格最多两只角色气泡，按左到右、上到下排列，尾巴明确指向说话人。

## 第 1 页｜还有什么会出现？（5 格）

排版：上方一横格，中间两格，下方两格。承接上一章，不重新介绍主角。

1. **远景／承接。** 两人背向镜头，站在淡淡透明光纹上；眼前是被光照亮的广阔水面。小昆略向前探身，小君站在旁边。**无台词。**
2. **小昆近景。** 他左右张望，手扶一条背包肩带，语气好奇而非抱怨。**小昆：下一页呢？怎么还都是水？**
3. **小君中近景。** 她原本看着水面，忽然注意到上方变化，轻轻抬手示意。**小君：欸，你看上面。**
4. **两人越肩仰视。** 上方水色层次开始改变，画面留出纵深；不画已完成的蓝天、实体天顶或星空。**小昆：上面也有水？**
5. **双人反应。** 小君仰头，小昆顺着她的视线看；两人是发现新变化，不是对机制下结论。**小君：嗯……好像正在分开。**

注意：第 4、5 格是进入第二日的视觉衔接，不让角色的话引发创造；下一页由经文明确事件的发起者。

## 第 2 页｜水与水之间（5 格）

排版：上方横格，中间两格，下方两格；用纵向空间变化区别第一章的水平水面。

1. **深远环境。** 上下水色之间出现可辨认的间隔；主角很小地处在画角。**经文旁白：神说：“诸水之间要有空气，将水分为上下。”**（创 1:6）
2. **宽阔仰视。** 上方水色与下方深水之间的空间逐渐展开；不画机械切割、玻璃罩、瀑布墙。**无台词。**
3. **小昆侧面中景。** 他先看脚下，再仰头，手指向两者之间。**小昆：你看，中间空出来了。**
4. **小君越肩镜头。** 视线越过小昆的手，能同时看见上下层次和其间空间。**小君：对，下面还是水，上面也还有。**
5. **双人中景。** 两人仰头看得入神，小昆轻轻揉后颈，小君也放低一点视线。**小昆：哇……我脖子都快看酸了。**

注意：“空气”保留和合本用词；画面表达经文中的广阔空间，不把这一格画成现代氧气分子课堂，不断言“上面的水”的具体物理构造。

## 第 3 页｜天空展开（3 格）

排版：上面两条窄横格，下面一大格约占半页。此页不安排笑话，用空间感呈现事件。

1. **环境中远景。** 镜头注视水与水之间展开的空间。**经文旁白：神就造出空气，**
2. **上下层次的纵深画面。** 下方水面、其间空间和上方水色层次分明，但没有实体分隔墙。**经文旁白：将空气以下的水、空气以上的水分开了。**
3. **大远景。** 广阔的天空与下方水面成为主体；小昆、小君并肩背影缩小到边角，站位不离开观察空间。**经文旁白：事就这样成了。**（以上创 1:7）

## 第 4 页｜这是第二日（5 格）

排版：第一行横格；第二行两格；第三行两格，晚上与早晨使用对应构图。

1. **广角仰视。** 天空占画面大部分，两人的身影只占底部少量空间。**经文旁白：神称空气为“天”。**（创 1:8）
2. **小昆近景。** 他放下揉后颈的手，仍看着上方。**小昆：原来，我们每天抬头看的天空，是这样开始的。**
3. **双人中景。** 小君笑着侧头，小昆略不好意思。**小君：你平时有认真看吗？**／**小昆：有啊……看会不会下雨的时候。**
4. **静景／晚上。** 天与水转暗；两人安静站着，没有星月。**经文旁白：有晚上，**
5. **同机位／早晨。** 天与水重新明亮，没有太阳升起。**经文旁白：有早晨，是第二日。**（以上创 1:8）

注意：第 3 格只是现代生活对话，不画下雨的回忆插图；不在第二日擅加“神看着是好的”旁白。

## 第 5 页｜水开始聚集（5 格）

排版：上方横格，中间两格，下方两格。将镜头从仰视天空转为俯视水面。

1. **水面远景。** 明亮天空下仍以水为主；先出现命令，随后画结果。**经文旁白：神说：“天下的水要聚在一处，使旱地露出来。”**（创 1:9）
2. **俯视环境。** 水面向聚集处延展，开始出现不同的水陆轮廓；不是挪亚洪水，也不画灾难海啸。**无台词。**
3. **双人越肩。** 小昆注意到远方一块土色，抬手指给小君看。**小昆：那边！那块深色的是什么？**
4. **小君近景。** 她眯眼确认，看向同一方向，不急着下判断。**小君：我看到了。刚才还没有的。**
5. **环境特写。** 较近的水边显出裸露泥土和岩面，尚无青草。**小昆（画外气泡，尾巴向画外观察位置）：不是水……是地！**

## 第 6 页｜旱地露出来了（4 格）

排版：上半页一大格，中间两小格，下方横格。保留观看变化的时间，不把全页塞满对白。

1. **大远景。** 旱地和水的聚处显露清楚，形成广阔、无植被的景观；两人在透明观察空间内，没有踏上土地。**经文旁白：事就这样成了。**（创 1:9）
2. **地貌细节。** 裸露地面的纹理、水边高低变化，构图以低机位拉出纵深；不复制现实世界地图。**无台词。**
3. **小昆反应近景。** 他眼睛睁大，目光沿着新出现的地面移动。**小昆：刚才只有一点点，现在能看到这么远！**
4. **双人背影横格。** 小君和小昆一起看向远处水陆交界，手自然放下。**小君：这下，终于不只是水了。**

注意：显露变化属于叙事性视觉表现，不宣称经文记载了具体速度、板块运动或地貌形成机制。

## 第 7 页｜地与海（5 格）

排版：上方两格对照地与海，中间一横格，下方两格。

1. **旱地近景。** 土地向远处延伸，仍无植物。**经文旁白：神称旱地为“地”，**
2. **水面远景。** 水的聚处连接远方天空；没有鱼、船、海鸟。**经文旁白：称水的聚处为“海”。**
3. **水陆同框。** 清楚看见地与海，不用二分符号图解。**经文旁白：神看着是好的。**（以上创 1:10）
4. **小昆中景。** 他在地与海之间来回看，笑着感叹。**小昆：现在说“海边”，终于有个“边”了。**
5. **小君近景／接话。** 小君忍不住笑，小昆在旁边也笑，不变成夸张表情包。**小君：哈哈，还真是。**

## 第 8 页｜地上要长出什么？（6 格）

排版：前面三条较宽的景物格承载同一句经文，下面三小格。长命令分格连续呈现，避免缩成小字。

1. **裸露土地广景。** 先放命令，不提前把地画满植物。**经文旁白：神说：“地要发生青草和结种子的菜蔬，**
2. **地面横景。** 镜头沿土地移动，开始可见细微绿色变化。**经文旁白：并结果子的树木，各从其类，**
3. **另一处地面细节。** 不画指定苹果或伊甸园的特殊树；命令在这一格收尾。**经文旁白：果子都包着核。”**（以上创 1:11）
4. **小昆中景。** 他俯身朝观察空间外看，未触碰地面，发现绿色。**小昆：小君！下面变绿了！**
5. **小君蹲下观察的近景。** 她在原有透明观察空间内蹲下，看向更远处。**小君：不只这里，你看那边也是。**
6. **低机位景物。** 绿色出现在土地多处，从近景延伸到远景。**经文旁白：事就这样成了。**（创 1:11）

## 第 9 页｜不只是一片绿色（6 格）

排版：两格、两格、下方一横格加一细节格；重点是区分植物细节，而不是不断重复大森林。

1. **青草近景。** 细致的草叶和地面纹理，背景保留岸边关系；不加昆虫。**经文旁白：于是地发生了青草和结种子的菜蔬，**
2. **植物中近景。** 草本植物呈现不同叶形、茎干与结种子的细节；不画人工整齐农田。**经文旁白：各从其类；**（以上创 1:12）
3. **小昆蹲姿中景。** 他看向不同植物，手留在膝边，不摘叶子。**小昆：远看都是绿的，近看还真的不一样。**
4. **小君与景物同框。** 她指向两种不同叶形，小昆循着她指的方向看。**小君：你看，这种叶子圆圆的，旁边那种细长。**
5. **两人观察视线的越肩近景。** 小昆发现植物上小小的种子结构，神情认真。**小昆：上面这些小小的，是种子吧？**
6. **种子细节。** 镜头给出可辨认的种子结构，不画现代科普标签。**小君（画外）：应该是。刚才那句也有说“结种子”。**

注意：特定叶形和种子外观只是植物多样性的艺术设计，不声称经文列出了这些物种。

## 第 10 页｜树上也有了果子（5 格）

排版：上方大横格展示树，中间两格，下方两格；将关注点从地面抬到树冠。

1. **树木中远景。** 不同树形与结出的果实出现，近处草本、远处树冠分层；不是先青草后树木的科学时间线，而是依经文文字逐项展示。**经文旁白：并结果子的树木，各从其类；**
2. **果实特写。** 展示树上的完整果实，另以一个很小的无边框剖面示意显出内部种子；这是读者视角，不是主角摘切果子。**经文旁白：果子都包着核。**（以上创 1:12）
3. **小昆仰头近景。** 他眼睛跟着枝头移动，语气像发现了新东西。**小昆：树上真的有果子了！**
4. **双人侧面。** 小君看看小昆，又看看果子，略带笑意。**小君：你是不是看饿了？**
5. **小昆反应与小君接话。** 小昆笑着摇头，手扶肩带，没人伸手摘果子。**小昆：本来没有，你一说就有一点了。**／**小君：哈哈，是你先盯着看的。**

注意：本章不画生命树、分别善恶树、蛇或禁果；不把普通果树具体命名为圣经没有指定的物种。果实剖面仅为展示“包着核”，不添加摘食事件。

## 第 11 页｜这是第三日（4 格）

排版：上方大横格展示完成后的环境；中间两格对应晚上与早晨；下方一横格人物反应。

1. **完整景观。** 天、海、陆地、青草、结种子的植物与果树同框，两人不占画面中心。**经文旁白：神看着是好的。**（创 1:12）
2. **晚上／环境。** 相同景物转为幽暗，树只留下轮廓，没有月亮、星星、萤火虫。**经文旁白：有晚上，**
3. **早晨／同构图。** 柔和无形光重新照亮环境，不画旭日。**经文旁白：有早晨，是第三日。**（以上创 1:13）
4. **双人中景。** 小昆伸出三根手指，再看向四周，小君跟着环顾。**小昆：才第三天，就跟刚来的时候完全不一样了。**

## 第 12 页｜还有一个问题（5 格）

排版：上面两格、中间两格、下面大横格；预告排在末格外的页脚，不另算漫画格。

1. **双人静景。** 两人并肩看树与海，小君语气轻松，接住上一页的感叹。**小君：刚才还在找陆地，现在连树都有了。**
2. **小昆近景。** 他正要点头，突然想到第一章的问题，视线转向天空。**小昆：等一下，我还有个问题。**
3. **小君近景。** 她转身看他，带一点熟悉朋友的笑。**小君：好，你问。**
4. **小昆仰视中景。** 他把手放在眉前寻找光源；画面不出现太阳轮廓。**小昆：都第三天了，太阳到底什么时候出现？**
5. **大背影格。** 两人站在淡淡透明观察空间内一起抬头，前景是草木、远处是海与明亮天空，没有光体。**小君：对哦……我也想看。**

页脚片尾：**下一章｜日月星辰**

## 绘图前连续性检查（不放进 App）

1. 12 页共 58 格；大格负责空间变化，小格负责植物细节、动作与自然接话。
2. 两人衣服、鞋子与包全程一致；小君只能有一个包，小昆不能多出一条无主肩带。
3. 两人留在虚构观察空间，没有踩到尚未出现的陆地，没有摘植物、吃果子或影响创造。
4. 第二、第三日不画太阳、月亮、星星、鱼、鸟、走兽、昆虫、亚当或夏娃。
5. 第二日不加经文未写的“神看着是好的”；第三日保留地海完成与植物完成的两次评价。
6. 经文词语保留；长句依序分格，不擅自把“菜蔬”换成某个具体蔬菜，不将“空气”解释成氧气制造。
7. 空间展开、旱地显露、植物细节为视觉转述；不声称漫画补出的速度、形状或物种是经文明说。
8. 植物可以细画，动物不能为了可爱提前出现；不加海鸥、蝴蝶、蜜蜂或水里游鱼。
9. 先审文字，再锁定逐页稿，之后才生成图片。本稿现已批准；未来修改剧情或对白仍须先确认，制作说明不能加入线上阅读内容。
