## 本轮精修重点

- 保留用户指定的提约定→决定今天读→翻包发现忘带→去借书顺序。
- 找不到书后由纸条指向旧书室；先问人、再寻找，不突然闯入一个无关房间。
- 借阅柜台无人：两人只打算在馆内先读，不带走书；书架取书、放桌、打开、环境淡去均有动作交代。
- 页末钩子不全靠问句：纸条、显露的书名、浮起的光点、消失的桌子、水岸、脚步等承担推进。
- 穿越后先表现害怕与互相照应，再被发生的变化吸引；不瞬间忘记紧张。
- 创造旁白承载经文信息，现代主角回应可见的事；不默认两人能听到读者的旁白，不凭旁白突然全知。
- 神秘图书馆的完整解释尚未批准，作为待回收悬念记录，不另加管理员角色或支线。

## 完整因果与情绪

提起约定 → 不再拖延 → 忘带书 → 去借书 → 柜台无人 → 普通书架空位 → 搬迁纸条 → 旧书室搜寻 → 拂灰辨认 → 搬到桌边打开 → 读经 → 光点异常 → 遮光验证 → 光点浮起并增加 → 家具与房间淡去 → 两人靠近 → 黑暗深水 → 光出现 → 天地、生命与人依次出现 → 安静观看 → 想知道后续。

情绪：轻松/不好意思 → 行动 → 察觉异样 → 小心好奇 → 找到书的轻松 → 不可解释的惊讶 → 紧张 → 互相照应 → 逐渐专注 → 敬畏与安静 → 继续阅读的愿望。
