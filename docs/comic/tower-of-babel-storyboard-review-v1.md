## 故事目标、已知信息与因果

第十二章先概述后裔按宗族、土地、语言分居。本章开头明确**回到大家原本说同一种语言的阶段**，解释分散与语言不通的来由，不演成全地人先变多语、后来又恢复一种语言。

完整链条：众人原本语言相通 → 向东迁移，在示拿地平原定居 → 商量做砖、烧砖，使用砖和石漆 → 为传扬自己的名、避免分散，决定建城造塔 → 工程展开 → 耶和华降临察看，并说到他们同民同语、开始做的事及所图谋的事 → 耶和华要变乱他们的口音 → 人们彼此听不懂，合作不再顺畅 → 耶和华使他们从那里分散，工程停下 → 解释巴别之名，接回上一章“不同语言与邦国”的问题。

动机先于行动：第3页说清“传扬自己的名”和“免得分散”，第4页才展开城塔工程。不能只说“塔太高，所以神把塔打倒”，也不把普通建筑技术、群体合作本身写成罪。

## 文字与事实边界

- 全章从左到右、从上到下。对白气泡尾巴指向小昆或小君；古代人物可有开口、手势和倾听动作，但本稿不编他们逐字说了什么，也不用乱码、现实语言辱骂或滑稽口音代表语言不通。

- 语言彼此不通依据11:7、9；分散及停工依据11:8。第6页的工作配合中断是对效果的视觉示意，不添加一场具体工伤或领袖惩罚。
- 没有记载各语言名称、每个家庭去往哪里、巴别塔精确高度或建筑倒塌，不添加对应地图、米数或结局。
- “巴别”之名按11:9联系语言被变乱；不把这里写成现代语言学词源课，也不重演上一章宁录的国度记载。
