## 用户强调的因果链

放学提起读经约定 → 几次拖延后决定今天开始 → 翻包发现两人都没带 → 为了借圣经才去图书馆 → 门开着但没有人、主灯没亮 → 普通书架找不到 → 看到旧书搬迁线索 → 进入旧书室/兼储藏空间 → 在角落找到积灰的旧圣经 → 小心移到桌上 → 打开并阅读 → 发现异常光点 → 遮住阳光仍亮 → 光粒子升起并包围两人 → 房间、桌子与书渐渐淡去 → 进入黑暗深水的观察空间。

不能省掉“为什么去图书馆”“为什么去旧书室”或“怎样进入圣经世界”。不能画成现代主角自己带着圣经去图书馆。不能提前画神秘光，破坏“先以为是阳光，再发现不是”的推理。

## 第一页：用户指定的对白起点

不要直接从“今天真的要读咯”或“没带圣经”开始。必须先保留原有约定的对话。

1. 放学铃响。小君：「欸，今天放学后，你有空吗？」小昆：「有啊，怎么了？」
2. 小君：「我们不是说好，要一起读圣经吗？」小昆：「啊，对哦！讲了好几次了。」
3. 小君：「结果每次都说，下次再开始。」小昆：「那就今天，不拖了！」小君：「好，那今天真的开始读咯。」
4. 小昆翻包，停住：「欸，等一下……我好像没带圣经。」
5. 小君检查自己的包：「我的也放在家里了。」小昆：「不会吧，今天终于要读，结果两个人都没带。」
6. 小君：「去图书馆找找？说不定有得借。」小昆：「好，走！今天不说下次了。」

上述是最近完整审核稿的具体写法；核心顺序和前段对白来自用户明确纠正。后续润色不能破坏此顺序。精确气泡仍须对应最终审定稿。

## 首尾呼应

找到书坐下后，小昆说「那今天先看一页哦」。不要在学校又重复一次同样对白。
末页：小昆「那他们后来怎么样了？」小君「你不是说，今天只看一页？」小昆「再看一点嘛。」预告《伊甸园》。

情绪变化：起初觉得可以继续拖 → 今天主动想办法 → 好奇夹着紧张 → 进入创造后的惊讶 → 安静观看 → 想继续读。不能把两人写成每页轮流讲课。

## 连续性账本

- 服装与背包：沿用 AGENTS.md 和批准人物图，不在校园换校服后直接跳回原衣服。
- 旧圣经：厚、旧、积灰、字迹磨损但可辨识；不是铁链封印魔法书。由旧书架取得，轻放旧木桌，阅读后才出现异常。
- 光线：图书馆没开主灯，但白天窗光能看清书。普通灰尘没有独立发光，书中光点被手掌遮住日光仍亮。
- 地点：普通书架 → 后方旧书室。新的第4–5页都必须使用旧书室背景，不能混用之前明亮新书架的画面。
- 穿越：解释家具和书如何离开画面；穿越后无实体圣经在手，角色在既定观察空间内，不落水、不改变创造。
- 旧图片：创造部分可优先保留，但必须逐页检查新旧场景、对白和编号，不能仅靠改标题声称图片已更新。

## 仍属提案、不可擅自写死的设定

- 搬迁纸条「旧版书籍已移至后方旧书室」、门牌和开门状态已随16页整稿确认；不添加越锁、禁止入内或盗取书籍情节。
- 图书馆为何无人：用户要求表现异常安静；助手提出“值班人员短暂离开”为可能解释，用户尚未确认。不要把该解释画成已定事实。
- 后续返回现实应回应图书馆/旧书室的疑问，具体时间和答案待规划，不添加神秘管理员、选中者身份或旁支任务。
