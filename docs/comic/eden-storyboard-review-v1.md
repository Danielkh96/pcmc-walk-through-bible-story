## 1. 第二个故事讲什么

第一章讲神创造天地万物；第二章把镜头拉近，讲人在神所预备的世界里怎样开始生活：亚当领受生命，被安置在伊甸园，得到食物、照料园子的责任和关于分别善恶树的吩咐。园里有许多动物，但没有与他相配的伴侣。神使亚当沉睡，用他的肋骨造成女人，领她来到他面前。故事结束在两人相伴、坦然生活的美好状态。

这章的核心不是参观风景，而是从“这里什么都有”走到“原来人还需要与自己相配的同伴”。供应、责任、信任与相伴贯穿剧情。蛇的试探、吃果子及离园留到后续独立故事，章名暂拟《试探与选择》，本次不展开或授权该章。

## 3. 上一章怎样接过来

上一章末页：小昆与小君坐在透明观察空间里。小昆问“那他们后来怎么样了？”，小君拿“今天只看一页”打趣，小昆回答“再看一点嘛”。

本章从同一姿态、同一观察空间继续。小昆对那两位成人的来历产生兴趣。漫画用清楚的“回看”叙事框，带读者细看人的受造；不是第八日再次造人，也不是现代主角启动第二次穿越。

现代主角只观察。他们没有实体圣经在手，不摘果子，不踏入园中，不接触动物，也不让圣经人物回应他们。经文旁白是给读者看的，不是两人能听到的神秘讲解声。因此，现代对白只回应他们能看到的动作与表情；他们不会从旁白自动获得名字、树名、禁令或神的意图。

## 4. 完整故事梗概与因果链

因为第一章只远远看见了成人男女，小昆仍想知道他们怎样来到这里，所以两人继续观看。叙事回到人的受造：神用尘土造人，赐他生命，并把他安置在伊甸园。

园中有悦目的树木、可吃的果子和滋润园子的河流，生命树与分别善恶树也在其中。因为这园子被交托给人，他的生活包含修理、看守；神同时说明哪些果子可以吃，哪一棵树的果子不可吃及违背的后果。

随后，经文点出“独居不好”。动物来到亚当面前，他给它们起名；小昆与小君也跟着辨认、观察动物，气氛暂时轻快。但热闹过去，仍没有与他相配的伴侣。这不是神尝试失败，而是叙事让读者看清人与动物的不同。

神使亚当沉睡，取他的肋骨造成女人，领她来到他面前。亚当认出她与自己同属、相配。画面从一个人的园子变为两人的生活，回扣上一章看到的男女背影。小昆因此继续追问：他们会一直住在这里吗？下一章由此自然展开。

情绪：好奇 → 生命初现的安静 → 园中的丰盛 → 责任与严肃界限 → 动物带来的轻松 → 缺少同伴的停顿 → 相遇的喜悦 → 平静中的期待。

全章共用的连续性约定（以下每格均适用，无需在每格重复）：

1. 小昆背包始终背在身上；小君始终一只斜挎包。没有人取出书、手机、水壶或其他道具。表中未写“手抬起”时，手自然垂放或扶原有包带。
2. 第1页前两格两人坐着，之后明确起身。后续均站在原有观察空间内；双人正面或侧前景保持小昆左、小君右。背影、越肩必须按真实机位保持空间，不机械镜像。
3. 场景变化是漫画镜头与回看叙事，不增加光门、控制按钮、口令或“想看就能操纵时间”的新能力。透明边界只在需要辨认站位的格子淡淡出现。
4. 园中使用连续的柔和日光。沉睡不等于入夜。未经经文交代不插入日历、额外天数或夜晚。
5. 神只由旁白说明其行动，不画身体、脸、手、影子或人形光团。不把观察空间的光粒子画成创造人的力量。
6. 成年人采用头肩景、背影、远景及不透明的树干、灌木遮挡敏感部位；犯罪之前没有叶裙、皮衣。遮挡不是衣服，也不以裸露做笑点。
7. 园子、河形、植物和动物外观是艺术表现；不声称是伊甸的精确地理。两棵树有不同轮廓以利识别，但没有经文以外的发光能力或苹果品种设定。
8. 【叙事框】是虚构框架/时间提示；【转述】是依据经文的改写；【原句】按指定译本核对；【对白】是现代主角虚构对白。只有“上画文字”列的文字会进入正式漫画，其他全部是制作备注。
9. 本章不增实体工具。第4页扶正幼枝、拨开遮光枝叶是“修理、看守”的可视化生活细节，不称为经文逐项记载的行为。
10. 现代主角不读出旁白、不凭空解释经文；经文事件不由他们的台词、愿望或动作触发。
