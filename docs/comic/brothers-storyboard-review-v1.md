## 故事讲什么

亚当与夏娃离开伊甸园后，生下该隐和亚伯。长大的兄弟一个种地，一个牧羊。他们献上供物，神看中了亚伯和他的供物，却没有看中该隐和他的供物。该隐发怒，神先提醒他面对罪的危险；他仍攻击并杀害弟弟。随后，他否认自己的责任，面对土地不再给他效力、流离漂泊的刑罚。神也给他保护，禁止别人任意杀他。故事以该隐离开、前往伊甸东边的挪得收束。

本章目标：让读者看清「发怒 → 听见提醒 → 仍然施暴 → 否认 → 面对结果」的完整过程。小昆、小君从好奇转为沉静，承担观察与情感反应，不轮流讲道理。

## 经文、文字类型与画面边界

- 范围：创世记 4:1–16；开头承接创世记 3:23–24。
- 查核译本：和合本简体 CUVS（网页标示 Public Domain）。[创世记第四章原文](https://www.biblegateway.com/passage/?search=Genesis%204&version=CUVS)。
- **本稿所有圣经人物对白与经文旁白统一标为「经文转述／转述」，不是逐字原文**。采用现代标点与用语，不把「什么」「儿子」「控制」等改写冒称逐字引文。
- 「虚构」只用于小昆、小君的对白；「编辑文字」用于时间字幕、页角。镜头、器具、肤发外貌及动作展开均是艺术表现，不能宣称经文逐一记载。
- 正式画面只印表格「对白／旁白」栏中的引号内文字；类型标记、镜头说明、依据、页内工作标题不印进漫画。神言框可保留小字说话人「耶和华」，使学生不会误认成旁白。
- 经文没有在本段说明供物未被看中的具体原因。不添加腐烂供物、献蔬果必被拒绝、天火验收、亚伯嘲笑该隐或神只喜爱牧羊人的解释。
- 创4:8采用上述译本，其正文没有「我们到田里去」的邀请句；本章只交代两人在田间说话，不编造谈话内容。
- 神不具象化；「罪伏在门前」「血从地里哀告」不变成魔物或鬼魂。记号不设计形状、颜色、位置，不新增刺青或肤色设定。
- 该隐杀亚伯须说清；采用成人动作中景、倒下局部和远景后果，不展示血腥伤口，不指定经文未载的凶器。
- 第4章只到4:16；不提前画该隐妻子、以诺城、塞特、洪水或挪亚。

## 承接与因果

第三章最后：亚当与夏娃穿皮衣走出园子，小昆、小君在观察空间观看，预告「园外的两兄弟」。本章第1格沿用人物方向、服装与山谷，不重演离园。

因为故事继续发生在园外，所以先交代家庭诞生；因为两兄弟已经成长、各有生活，所以交代种地和牧羊，再呈现献供物。该隐因未被看中而发怒，但是他先听见了提醒；他仍然施暴，于是亚伯死亡、该隐面对追问与刑罚。该隐害怕被杀，所以神对此作出回应；保护没有取消已经宣告的后果，最后该隐离开。

现代主角知道：已经看过创造、伊甸园与离园；能观察眼前时间变化、人物行动，并听见场景内的对话。他们不知道：角色未说出的动机、献供物区别的原因、记号具体样子、其他人的来历、下一步结局。叙事旁白是给读者的，不自动变成他们的知识。跨时间只是观看时段推进，不增设孩子操控时间的能力。

现代主角持有：小昆一只深蓝背包；小君一只棕色斜挎包；双手没有实体圣经、手机或新装备。想做的事：继续看园外生活；事件转重后，允许安静观看与短暂停顿。他们始终不被古代人物看见，不接触或改变古代世界。
